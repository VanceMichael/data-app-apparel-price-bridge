# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## styles

商品实物规格；充绒量为克。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 款式编号 |
| `generation` | string | 上市代 |
| `fill_g` | number | 充绒量 |
| `material` | string | 面料 |
| `family` | string | 商品系列 |

## comparability

商品人员对可比性的决定；撤销不改变销售事实。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 关系编号 |
| `old` | string | 旧款 |
| `new` | string | 新款 |
| `state` | string | 确认或拒绝或撤销 |
| `known` | string | 知悉日期 |

显式引用：`old` → `styles.id`；`new` → `styles.id`。

## sales

金额为整行人民币分；平台补贴不含客户支付。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 原订单行 |
| `period` | string | 销售所属月 |
| `style` | string | 款式 |
| `channel` | string | 渠道 |
| `qty` | integer | 件数 |
| `customer_cents` | integer | 客户实际支付 |
| `platform_cents` | integer | 平台承担 |
| `brand_cents` | integer | 品牌优惠 |
| `material_batch` | string | 耗用物料批 |

显式引用：`style` → `styles.id`；`material_batch` → `costs.id`。

## costs

物料成本为每件分；数量与采购市场报价无直接替代关系。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 物料批 |
| `unit_cents` | integer | 实际单位成本 |
| `available` | string | 投入期 |

## fees

费用是独立对账事实；撤销引用原费用。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 费用编号 |
| `order` | string | 所属订单行 |
| `kind` | string | 扣点或物流 |
| `amount_cents` | integer | 费用分 |

显式引用：`order` → `sales.id`。

## returns

退回关联原单；退款含义不能由商品件数推定。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 退款编号 |
| `order` | string | 原订单 |
| `qty` | integer | 退回件数 |
| `customer_cents` | integer | 退客户金额 |
| `platform_reversed_cents` | integer | 返还平台补贴 |
| `fee_reversed_cents` | integer | 已确认费用退回 |
| `known` | string | 知悉日期 |

显式引用：`order` → `sales.id`。

## subsidy_pools

共享渠道补贴；商品范围按数组精确适用。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 池编号 |
| `limit_cents` | integer | 补贴总额度 |
| `styles` | array | 适用商品 |
| `channel` | string | 适用渠道 |

## campaigns

活动确认形成渠道承诺；每件价及门槛为分。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 活动编号 |
| `style` | string | 商品 |
| `pool` | string | 补贴池 |
| `volume` | integer | 情景件数 |
| `coupon_cents` | integer | 每件券 |
| `threshold_cents` | integer | 满减门槛 |
| `discount_cents` | integer | 满减额 |
| `stackable` | boolean | 允许叠加 |
| `settlement_floor_cents` | integer | 最低每件结算 |
| `reserved_cents` | integer | 已确认占用 |
| `state` | string | 拟议或已确认 |

显式引用：`style` → `styles.id`；`pool` → `subsidy_pools.id`。
